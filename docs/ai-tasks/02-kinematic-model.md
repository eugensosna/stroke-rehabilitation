# Задача 2. Модель кінематичних показників (чисті модулі TypeScript + тести)

## Контекст

Зараз `WristTracker.ts` / `useWristMotion.ts` сегментують рухи лише за точкою зап'ястка з порогами 0,03 і 0,008,
без фільтрації, нормування і калібрування. Розділ 2 роботи задає повну модель. Її треба реалізувати
як набір модулів **без залежності від Vue і DOM**, з модульними тестами. Джерело формул:
`~/prj/znu/magistr/chapters/20-chapter-2.adoc`.

## Що зробити

Створити `src/model/` (кожен файл — чисті функції/класи, JSDoc з посиланням на формулу):

| Файл | Зміст |
|---|---|
| `coords.ts` | ізотропні координати `P_i = (x_i·W, y_i·H, z_i·W)`; індекси: кінчик пальця `4k`, ПФС `4k−3`, `k = 1..5` |
| `oneEuro.ts` | фільтр 1€ (Casiez et al., 2012): `alpha = 1 / (1 + 1/(2π·fc·Δt))`, `fc = fcMin + beta·|dx̂|`, похідна згладжується з фіксованою `dCutoff`; `Δt` — з часових міток, не номінальна частота; `reset()` |
| `handFilter.ts` | 63 фільтри (21 точка × 3 координати); кадр без кисті не оновлює стан; якщо кисті немає довше `tLost`, фільтри скидаються |
| `scale.ts` | масштабний множник `s = ‖P9 − P0‖` |
| `metrics.ts` | кут `φ(a,b,c) = π − arccos(...)` з обмеженням аргументу arccos до [−1; 1]; кути суглобів (для k ≥ 2: `φ(0,4k−3,4k−2)`, `φ(4k−3,4k−2,4k−1)`, `φ(4k−2,4k−1,4k)`; для великого: `φ(1,2,3)`, `φ(2,3,4)`); `Φ_k`; `Φ̄`; `d_k = ‖P4 − P4k‖ / s`, k = 2..5; `O = (1/5)·Σ‖P4k − P0‖ / s`; функція `computeFrameMetrics(frame) → FrameMetrics` |
| `temporal.ts` | амплітуда повторення `A_m = max − min`; інтервали `T_m = t_m − t_{m−1}`; `f = 1/T̄`; `V = σ_T/T̄·100 %` з `σ_T` за `(M−2)` у знаменнику; інтервали з паузою виключаються; при `M < 3` — `null`, а не NaN |
| `isolation.ts` | `I_k = 1 − (1/4)·Σ_{j≠k} min(1, ΔΦ_j/ΔΦ_k)`; при `ΔΦ_k ≈ 0` — `0` |
| `percentile.ts` | процентиль з лінійною інтерполяцією за NIST/SEMATECH e-Handbook (`p(N+1)`, обмеження на краях) |
| `calibration.ts` | за записом значень показника і напрямом (`increasing` / `decreasing`) → `{ xr, xg }` як 5-й і 95-й процентилі (для спадних — навпаки); `u = clamp01((x − xr)/(xg − xr))`; ознака `unavailable`, якщо `|xg − xr| < dxMin` |
| `adaptation.ts` | `thetaG(L) = thetaG1 + (L − 1)·dTheta` (не більше 1), `tHold(L)`, `tMax(L)`; правило «два вгору — один вниз» за формулою з символом Кронекера; рівень наступного сеансу = останній − 1 (у межах `[Lmin; Lmax]`) |
| `config.ts` | `ModelConfig` з усіма параметрами і типовими значеннями (`fcMin`, `beta`, `dCutoff`, `tLost`, `dxMin` для кожного показника тощо) |
| `index.ts` | публічний експорт |

Кути зберігати в радіанах, у градуси переводити лише для звітів (`toDegrees`).

### Тести

Додати Vitest (`vitest`, скрипт `"test": "vitest"`), тести в `src/model/__tests__/`:

- кут: прямий суглоб → ≈0, прямий кут → π/2; вироджені вектори нульової довжини не дають NaN;
- `d_k`, `O`, `s` інваріантні до масштабу і зсуву всієї кисті та до дзеркального відображення по x;
- ізотропні координати: однакове зміщення в пікселях по x і y дає однакову відстань при W ≠ H;
- фільтр 1€: на сталому сигналі з шумом дисперсія виходу менша за вхідну; на стрибку запізнення зменшується з ростом `beta`; нерівномірні `Δt` не ламають фільтр;
- процентилі збігаються з прикладом з NIST;
- калібрування для зростаючого й спадного показника, обмеження `u` до [0; 1], `unavailable`;
- `f`, `V` на штучних рівномірних і нерівномірних послідовностях;
- `I_k`: рухається лише заданий палець → 1, усі однаково → 0, сусідній більше → 0 (не від'ємне);
- сходи: послідовності успіхів/невдач дають очікувані рівні, межі `Lmin/Lmax` дотримуються, два успіхи на різних рівнях не підвищують рівень.

Опційно: генератор синтетичної кисті (`__tests__/syntheticHand.ts`) з параметрами згинання пальців — знадобиться і в задачі 3.

## Критерії приймання

- `src/model/` не імпортує `vue`, `pinia`, `window`, `document`.
- `npx vitest run` — усі тести зелені, покриття `src/model/` ≥ 90 % рядків.
- Кожна публічна функція має JSDoc з посиланням на формулу роботи.
