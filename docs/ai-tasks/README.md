Задачі 1 і 2 незалежні, їх можна виконувати паралельно.

## Загальні вимоги до всіх задач

- Стек не змінювати: Vue 3 + TypeScript + Vite + Pinia + Tailwind, графіки ApexCharts, ігри Canvas 2D.
- Увесь текст інтерфейсу українською мовою. Терміни: «ключові точки кисті», «вебкамера», «фахівець з реабілітації», «щипковий захват», «протиставлення великого пальця».
- Позначення в коді й коментарях відповідають формулам роботи (`phi`, `Phi`, `d`, `O`, `I`, `u`, `thetaR`, `thetaG` тощо); у JSDoc вказувати номер формули або назву підрозділу.
- Числові параметри (`fcMin`, `beta`, пороги, гістерезис, часи) не зашивати в код: вони в одному конфігураційному об'єкті з типовими значеннями, бо їх підбирають експериментально в розділі 3.
- Зображення кисті ніколи не зберігаються і в основному режимі не залишають браузер.
- Перед здаванням: `npm run type-check`, `npm run lint`, `npx vitest run` проходять без помилок.
- Не видаляти наявні ігри Arcade і Arkanoid, доки не з'являться нові вправи; після задачі 4 їх можна прибрати з меню.
- Не комітити без підтвердження користувача; в кінці коротко описати, що зроблено і що лишилося.
